Smart Identification of Fake Online Profiles Using Machine Learning

Machine Learning Python Django Random Forest Fake Profile Detection

This project detects fake social media profiles by analyzing profile and behavior-based features such as activity patterns, follower-following ratio, post frequency, user details, and content behavior. The system uses data preprocessing and model training to classify profiles as genuine or fake, reducing manual checking and supporting safer online communities.

Problem Fake accounts cause scams, impersonation, misinformation, and online trust issues.
Approach Feature analysis, data cleaning, model training, cross-validation, and classification.
Impact Supports faster and more reliable detection compared with manual verification.
